# Wos Tools

[简体中文](README.md) · [English](README_EN.md) · [日本語](README_JA.md)

Wos 向けのローカルツールです。現在はペットツールを収録しています。端末内で動作し、ネットワーク接続やゲームへの注入は行いません。

## 機能

- ペットツールはプレビュー画面の 6 項目の変化値を読み取り、選択した項目を等重みで合計して置換か再洗練かを判定します。合計が 0 の場合のみ優先順位で決めます。
- ペットツール専用のフローティング操作：タップで開始 / 一時停止 / 再開、長押しで状態表示、上下ドラッグで左右端に吸着、パネルから閉じられます。
- キャプチャはシステムに合わせて自動選択：34 以上はウィンドウ（グローバルへ切替可）、30〜33 はグローバル、29 以下は互換画面録画。
- 簡体中国語 / 繁体中国語 / 日 / 英を内蔵し、既定はシステムに追従。繁体中国語は zh-TW / zh-HK / Hant のシステム言語に対応。権限・キャプチャ方式・言語はホーム画面、ペット関連の設定は二階層目にあります。

## 使い方

ホーム画面でフローティング操作を有効にし、ゲームの洗練画面に切り替えてからボールをタップして開始します。Android 7.0（API 24）以降が必要で、ユーザー補助・オーバーレイ・通知の各権限を有効にしてください。互換キャプチャでは画面録画の許可も必要です。
