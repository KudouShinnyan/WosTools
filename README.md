# Wos Tools

[简体中文](README.md) · [English](README_EN.md) · [日本語](README_JA.md)

面向 Wos 的本机工具，目前包含宠物工具。本机运行，不联网、不注入游戏。

## 功能

- 宠物工具读取预览页六项变化值，按勾选项等权求和，决定替换或重新洗练；仅求和为零时按优先级决胜。
- 宠物工具专用悬浮球：单击开始 / 暂停 / 继续，长按看状态，可上下拖动贴边，面板内可关闭。
- 截屏按系统自动选择：34+ 窗口截图（可切全局）、30–33 全局截图、29 及以下兼容投屏。
- 内置中 / 日 / 英三语，默认跟随系统；主页放权限、截屏方式与语言，宠物相关配置在二级页。

## 使用

在主页开启悬浮控制，切到游戏洗练页后点浮球开始。要求 Android 7.0（API 24）以上，需开启无障碍服务、悬浮窗与通知权限；兼容投屏模式另需授权。
